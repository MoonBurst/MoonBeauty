09 MED tray icon absolute path accepted
   file: src/bar/tray/watcher.rs::resolve_icon
   why:  icon_name that starts with '/' is trusted verbatim:
           if icon_name.starts_with('/') { PathBuf::from(icon_name) }
         An SNI item can register IconName = "/etc/passwd.png" or
         "/home/user/.ssh/id_rsa" (as PNG-labeled bytes). The shell
         reads + decodes that file. Read-only, but exfils via UI (the
         bar renders the "icon" on screen) and leaks file existence.
   fix:  Reject absolute paths entirely. Whitelist [a-zA-Z0-9._-] for
         the basename, resolve strictly via hicolor / pixmaps search
         paths. If an app needs an absolute icon, it must use IconPixmap.

38 LOW-DoS SNI strings unbounded before display

   file: src/bar/tray/watcher.rs::fetch_tray_items

   why:  Id, Title, IconName, ToolTip read from hostile SNI peer with
         no cap. Title displayed directly; ToolTip rendered as a text
         widget on hover. 10 MB Title → 10 MB text widget → OOM.

   fix:  id ≤128, title ≤512, icon_name ≤128, tooltip ≤4096. Applied
         at materialization time.

   residual:  The initial zbus allocation for ToolTip's tuple
              (String, Vec<(i32,i32,Vec<u8>)>, String, String) is
              unpreventable at this layer — same class as finding 31.
              Real fix requires D-Bus message size cap at daemon.

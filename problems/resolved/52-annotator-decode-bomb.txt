52 MED-residual annotator image decompression bomb

   file: src/overlays/screenshot/annotator.rs::load_image

   why:  Finding 46 (batch 10) added an into_dimensions ≤16384×16384 gate
         but 16384² × 4 bytes = 1 GB decoded pixel buffer. A hostile PNG
         compressed to <100 KB (convert -size 16384x16384 xc:red) passes
         byte + dimension checks then OOMs at decode.

   fix:  image::Limits on the reader:
           max_image_width  = 16384
           max_image_height = 16384
           max_alloc        = 512 MB
         image::ImageReader::decode() now fails cleanly if decoded
         buffer exceeds budget.

   residual:  None at this layer. A PNG under 512 MB decoded can still
              cause moderate allocation, but that's within the shell's
              baseline memory budget.

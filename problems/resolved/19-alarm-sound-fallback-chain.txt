19 LOW alarm sound resolution uses cwd-relative fallback
   file: src/libraries/backend/audio.rs::resolve_alarm_sound_path
   why:  Tries four candidates:
           1. absolute path
           2. XDG_DATA_HOME/moon-beauty-shell/sounds/<basename>
           3. cwd/resources/<basename>                 [dev only]
           4. $CARGO_MANIFEST_DIR/resources/<basename> [dev only]
         Candidates 3 and 4 only work when running from the source tree
         or when CARGO_MANIFEST_DIR still exists post-install. In a
         packaged build they silently fail and the user gets no alarm.
         Also: if cwd happens to contain ./resources/<name>, a stray
         file there shadows the real sound.
   fix:  Drop candidates 3 and 4. The Nix flake's wrapProgram installs
         to the XDG data dir; keep that as the only lookup path.
         ImportAlarmSound already writes there. Update the settings
         help text to match.

21 LOW vendor directory contains a nested duplicate
   file: ./vendor/layershellev-0.14.2/  (Cargo.lock, Cargo.toml,
         examples/, src/)
         ./vendor/layershellev-0.14.2/layershellev-0.14.2/
         (contains the same tree again)
   why:  Cargo.toml patches layershellev to:
           layershellev = { path = "vendor/layershellev-0.14.2" }
         So the top level is what gets used. The nested copy adds ~15
         files of dead weight and confuses tooling (grep, IDE, cargo
         fmt --recursive) into thinking there are two copies of the
         same crate. Cargo sometimes complains about "found multiple
         package roots" when walking with external tools.
   fix:  Remove ./vendor/layershellev-0.14.2/layershellev-0.14.2/.
         Verify Cargo.lock hash for layershellev is unchanged after.
